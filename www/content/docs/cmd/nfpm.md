title: nfpm

Packages apps on RPM, Deb, APK, Arch Linux, ipk, MSI, MSIX, and macOS (app, dmg, pkg) formats based on a YAML configuration file

## Synopsis

nFPM is a simple and 0-dependencies apk, app, arch, deb, dmg, ipk, msi, msix, pkg, and rpm packager written in Go.
